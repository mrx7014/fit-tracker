**Fit Tracker** هو تطبيق أندرويد عملي لتسجيل التمرينات، متابعة التقدم، تنظيم جدولك الأسبوعي، وفهم أدائك من خلال إحصائيات واضحة وقابلة للمشاركة. صُمم التطبيق ليكون سريعًا أثناء التمرين، بسيطًا في الاستخدام، ومفيدًا على المدى الطويل.

## الإصدار 3.0.0

يقدم الإصدار 3.0.0 تجربة متكاملة لإدارة رحلة التمرين، بدايةً من إعداد بيانات المستخدم والدليل التفاعلي، مرورًا بالتسجيل السريع وجدول التمارين، ووصولًا إلى التحليلات الأسبوعية والشهرية ومشاركة النتائج.

### أهم المميزات

| المجال | ما يقدمه التطبيق |
| --- | --- |
| تسجيل التمرينات | تسجيل اسم التمرين والتاريخ والوزن والعدّات، مع دعم الأرقام العربية والهندية والفارسية. |
| الملف الشخصي | إدخال الاسم والوزن والطول عند أول تشغيل، وتعديل البيانات لاحقًا من الإعدادات. |
| الصفحة الرئيسية | تحية مخصصة، سلسلة التمارين، إجمالي الأوزان والعدّات والتمرينات، وسجل التمرينات. |
| الإحصائيات | ملخص أسبوعي أو شهري للجلسات والعدّات والأيام النشطة ومتوسط الوزن، مع رسم الوزن مقابل العدّات. |
| المشاركة | مشاركة ملخص الإحصائيات مع الأصدقاء أو عبر واتساب وتيليجرام ووسائل التواصل من قائمة مشاركة الهاتف. |
| جدول التمارين | إنشاء خطة أسبوعية منفصلة وإضافة أو حذف تمرينات لكل يوم. |
| الإنجازات | متابعة الإنجازات المحققة، سلسلة التمارين، وعدد التمرينات المختلفة. |
| الدليل التفاعلي | شرح خطوة بخطوة لأجزاء التطبيق مع إمكانية التخطي وإعادة الفتح من الإعدادات. |
| التذكيرات | تذكير يومي مع اختيار الساعة والدقيقة من الإعدادات. |
| التخصيص | عبارة تحفيزية قابلة للتعديل، الوضع الفاتح والداكن، ألوان النظام، واللغة العربية أو الإنجليزية. |
| البيانات | تصدير واستيراد نسخة احتياطية بصيغة JSON محفوظة على جهاز المستخدم. |

## التقنية

التطبيق مبني باستخدام Kotlin وJetpack Compose وMaterial 3. يتم حفظ بيانات التمرينات محليًا على الجهاز باستخدام SharedPreferences، مع توفير تصدير واستيراد JSON للنسخ الاحتياطي. الحد الأدنى المدعوم هو Android 8.0 (API 26)، والإصدار المستهدف Android 15 (API 35).

يتم بناء التطبيق ونشره من خلال GitHub Actions. عند تشغيل الـWorkflow مع تفعيل خيار Release، يحدّث الإصدار المحدد `versionName` و`versionCode` داخل إعدادات Gradle، ويحدّث إصدار التطبيق الظاهر في المصدر، ثم يبني APK وينشره على GitHub Releases.
