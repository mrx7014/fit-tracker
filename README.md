# IronLog

تطبيق Android بسيط لتسجيل أوزان تمارين المقاومة ومتابعة التقدم اليومي والأسبوعي والشهري.

## المميزات

- تسجيل اسم التمرين، التاريخ، الوزن، وعدد التكرارات.
- حفظ محلي على الجهاز بدون حساب أو إنترنت.
- ملخص سريع لحجم التدريب وعدد التسجيلات والـ streak الحالي.
- رسم نشاط آخر 7 أيام.
- سجل كامل مع إمكانية حذف أي تسجيل.
- واجهة عربية RTL مبنية بـ Kotlin وJetpack Compose وMaterial 3.

## التشغيل

افتح المشروع في Android Studio Ladybug أو أحدث، ثم شغّل `app` على جهاز/محاكي Android 8.0 أو أحدث.

```bash
./gradlew assembleDebug
```

الناتج يكون في `app/build/outputs/apk/debug/app-debug.apk`.
