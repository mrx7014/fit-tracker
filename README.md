# IronLog

تطبيق Android عربي لتسجيل أوزان تمارين المقاومة ومتابعة التقدم اليومي والأسبوعي والشهري.

## المميزات

- تسجيل اسم التمرين والتاريخ والوزن والتكرارات.
- حفظ محلي على الجهاز بدون حساب أو إنترنت.
- ملخص للـ streak وحجم التدريب وأعلى وزن.
- فلاتر متابعة أسبوعية وشهرية وسنوية.
- حركات انتقالية عند ظهور التمرينات وتغذية بصرية عند التسجيل.
- Backup وRestore بصيغة JSON من صفحة الإعدادات.
- ثيم نهاري وليلي.
- اختيار وحدة الوزن بين kg وlb مع تحويل العرض تلقائيًا.
- واجهة تعريفية Onboarding بنظام التالي/ابدأ الآن.
- شعار IronLog مخصص داخل التطبيق.
- خط Google Sans Flex للإنجليزية وNoto Sans Arabic للعربية.
- GitHub Actions للبناء التلقائي عند كل Push أو Pull Request.

## التشغيل

افتح المشروع في Android Studio Ladybug أو أحدث، ثم شغّل `app` على جهاز أو محاكي Android 8.0 أو أحدث.

```bash
./gradlew assembleDebug
```

> حسب الطلب، لم يتم تشغيل build في هذه الجولة بعد إضافة المزايا الجديدة.

## النسخ الاحتياطي

من **الإعدادات → تصدير نسخة احتياطية** احفظ ملف `ironlog-backup.json` في Google Drive أو أي مكان آمن. للاسترجاع، اختر **استيراد نسخة احتياطية** وحدد ملف JSON.
