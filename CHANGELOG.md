# Changelog

All notable changes to Fit Tracker are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Changed

- Ongoing maintenance is tracked here before the next tagged release.

## [3.0.0] - 2026-09-20

### Added

- First-launch profile setup for the user name, body weight, and height.
- Interactive application guide with skip support and a Settings action to reopen it.
- Weekly and monthly analytics with a weight-versus-reps chart and Android sharing.
- Separate weekly workout planning, achievements, customizable motivation, and daily reminders.
- Arabic, Persian, and English digit normalization for numeric inputs.
- Local JSON backup and restore for workout history.
- Arabic-first documentation, screenshots, and bilingual Android string resources.

### Changed

- Rebranded the application from Iron Log to Fit Tracker, including the package ID, logo, repository links, and application metadata.
- Reworked the home dashboard, floating navigation dock, profile cards, About page, and dark-mode system-bar appearance.
- Replaced the training-volume card with total weights, reps, and exercises.
- Updated GitHub Actions to Node.js 24-compatible action releases and release-only version selection.

### Fixed

- Prevented the floating add button from covering workout-history actions.
- Fixed localized analytics sharing and Android string-resource compilation.

## [2.0.0] - 2026-09-12

### Changed

- Preserved as the previous published application milestone.

## [1.0.0] - 2026-09-12

### Added

- Initial Android workout logging application.
