# Fit Tracker 3.0.0

## العربية

### أبرز الإضافات

- إعادة تسمية التطبيق بالكامل إلى **Fit Tracker**، مع تحديث اسم الحزمة ومعرّف التطبيق وروابط المستودع.
- إضافة إعداد الاسم عند أول تشغيل، مع إمكانية تعديل اسم المستخدم لاحقًا من الإعدادات.
- إضافة تسجيل الوزن والطول أثناء إعداد الحساب الأول، مع إمكانية تعديل بيانات الجسم من الإعدادات.
- إضافة دليل تفاعلي يشرح أجزاء التطبيق وطريقة استخدامها خطوة بخطوة، مع إمكانية التخطي وإعادة فتحه من زر **تعلّم التطبيق** في الإعدادات.
- إضافة عبارة تحفيزية قابلة للتخصيص من الإعدادات بدل العبارة الثابتة في الشاشة الرئيسية.
- استبدال مؤشر حجم التدريب بإجمالي الأوزان والعدّات والتمرينات.
- تغيير تسمية مؤشر الأداء إلى **سلسلة التمارين**.
- إضافة رسم بياني يوضح العلاقة بين الوزن والعدّات، مع اسم التمرين على كل نقطة ومحاور رقمية واضحة.
- فصل شاشة الإنجازات عن الإحصائيات، ونقل سجل التمرينات إلى الشاشة الرئيسية فقط.
- إضافة جدول تمارين أسبوعي مستقل مع إمكانية إضافة وحذف تمرينات كل يوم.
- إضافة إحصائيات أسبوعية وشهرية تشمل الجلسات والعدّات والأيام النشطة ومتوسط الوزن وتوزيع النشاط.
- إضافة مشاركة ملخص الإحصائيات الأسبوعية أو الشهرية مع الأصدقاء ووسائل التواصل من خلال قائمة مشاركة الهاتف.
- إضافة إعداد موعد مخصص للتذكير اليومي.
- تحسين بطاقة التحديث لتفتح صفحة GitHub Releases يدويًا.
- تحسين صفحة «عن التطبيق» وإضافة معلومات المطور MRX7014 وصورة الحساب وبيانات التطبيق.
- استخدام صورة الشعار الجديدة كأيقونة للتطبيق مع خلفية متناسقة.
- إصلاح ظهور أيقونات شريط الحالة والتنقل في الوضع الداكن.
- تحسين تصميم شريط التنقل ليظهر كـ floating dock، وتحسين بطاقات الحساب والتذكير اليومي.
- دعم إدخال الأرقام العربية والهندية والفارسية في الوزن والطول والتاريخ والعدّات.
- إضافة النسخ الاحتياطي والاسترجاع لبيانات التمرينات بصيغة JSON.
- تحسين سير عمل GitHub Actions لرفع إصدار Node.js إلى 24، وتحديث إصدارات Android Actions، وجعل اختيار الإصدار خاصًا بإصدارات GitHub Releases.
- إزالة بانر جلسات الفترة من الشاشة الرئيسية ومنع زر الإضافة العائم من تغطية أزرار سجل التمرينات.

### الإصدار

هذا هو الإصدار الرسمي **3.0.0** من Fit Tracker، وتم تجهيز بنائه ونشره من خلال GitHub Actions وGitHub Releases.

## English

### Highlights

- Fully renamed the application to **Fit Tracker**, including the package name, application ID, repository links, and branding.
- Added first-launch username setup with the ability to edit the username later from Settings.
- Added body weight and height during initial profile setup, with editable body metrics in Settings.
- Added an interactive step-by-step app guide with skip support and a **Learn the app** button in Settings to reopen it anytime.
- Added a customizable motivational phrase in Settings instead of a fixed home-screen message.
- Replaced the training-volume indicator with total weights, total reps, and total exercises.
- Renamed the performance indicator to **Workout streak**.
- Added a numeric weight-versus-reps graph with exercise names on each point and labeled axes.
- Separated Achievements from Statistics and kept workout history on the Home screen only.
- Added a standalone weekly workout plan with per-day exercise creation and deletion.
- Added weekly and monthly analytics covering sessions, reps, active days, average weight, and activity distribution.
- Added sharing for weekly and monthly analytics through the Android share sheet for friends and social media.
- Added a configurable daily reminder time.
- Redesigned the update card so it manually opens the GitHub Releases page.
- Improved the About screen with MRX7014 developer information, profile photo, and app details.
- Added the new logo as the application icon with a matching background.
- Fixed status-bar and navigation-bar icon visibility in dark mode.
- Improved the bottom navigation with a floating dock and refined the profile and daily-reminder cards.
- Added Arabic-Indic, Persian-Indic, and Arabic decimal digit support for weight, height, dates, and reps.
- Added JSON backup and restore for workout data.
- Improved GitHub Actions with Node.js 24-compatible action releases, updated Android actions, and release-only version selection.
- Removed the period-sessions banner from Home and prevented the floating add button from covering workout-history actions.

### Release

This is the official **3.0.0** release of Fit Tracker, built and published through GitHub Actions and GitHub Releases.
